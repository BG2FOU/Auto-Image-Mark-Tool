# Auto Image Mark Tool v0.3.0-rc.1

完整 JPG/JPEG 图形版预发布，支持 Windows x64 与 Ubuntu 24.04 / Linux amd64。

- 批量写入 GPS，支持保存、编辑并复用地点坐标列表。
- JPG 自适应水印与 GPS+水印组合流程；支持实时预览、逐图信息、CSV/TSV/XLSX 和剪贴板导入、预检、取消及结果报告。
- 保留原片，输出到另一个目录；按图像实际尺寸统一缩放文字、签名、间距和边距，不重采样原图。
- 保留方向、拍摄日期，输出 RGB/sRGB JPEG；水印字号按 pt 配置。
- Python/ExifTool 随包提供。照片、字体和签名不随公开包分发，请在设置中选择本地资源。GPS-only 无需字体/签名。

## 下载与使用

Windows 可直接使用单文件 EXE；目录 ZIP 解压后运行 `AutoImageMarkTool.exe`，保留 `_internal` 目录。Linux 使用 `sudo apt install ./auto-image-mark-tool_0.3.0-rc.1_amd64.deb`，然后启动 `auto-image-mark-tool`。DEB 的包内版本为 `0.3.0~rc1`。

请用 `SHA256SUMS.txt` 核对附件；源提交与固定工具链见 `BUILD_INFO.json`，许可清单见 `THIRD_PARTY_NOTICES.md` 和 `LICENSES.zip`。项目许可仍为 CC BY-SA 4.0，依赖按自身许可分发。

## 验证与限制

发布门禁要求 Windows 原生 runner 上目录版、单文件版、中文含空格路径自测，以及 Linux DEB 解包自测成功；冻结程序使用临时合成资源，检查真实 GPS/水印读回、方向、ICC、原日期、原片哈希、XLSX、设置和清理。测试结果与人工外观验收记录在 `docs/acceptance.md`。

当前只支持 JPG/JPEG；NEF 坐标、显影及水印留到后续版本。水印解码最多 6000 万像素、签名最多 1600 万像素，超限会明确拒绝。未做 Windows 代码签名。CI 的离线冒烟不等同于独立 Windows 10 电脑的桌面人工验收。
