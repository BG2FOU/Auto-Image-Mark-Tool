# GPS 图形预览版 0.2.0rc1

这一版提供可操作的坐标写入图形页面：添加 JPG/JPEG、逐行填写 WGS84 纬度和经度，或把同一坐标批量应用到勾选照片；整批预检、后台写入、进度、取消和逐张结果均已接入现有 ExifTool 工作流。输出是同名照片副本，原片保持不变。水印入口已预留，当前不可用。

## 下载

- Windows 10/11 x64：`AutoImageMarkGpsGui-v0.2.0-rc.1-windows-x64.exe`，原生 Windows runner 构建的单文件 GUI。
- Ubuntu 24.04 amd64：`auto-image-mark-gps-gui_0.2.0-rc1_amd64.deb`，安装后在应用菜单打开或运行 `auto-image-mark-gps-gui`。
- `SHA256SUMS.txt`：下载后核对文件哈希。

## 当前边界

- 图形页目前只放行 JPG/JPEG 的 GPS 写入。NEF 可导入，但在 Nikon 独立查看器验收副本前会被预检拦截。
- 水印、照片显影、表格导入、地点预设和字体/签名配置尚未进入本次预览版。
- 不包含用户照片、商业字体或签名图。项目许可证保留 CC BY-SA 4.0；依赖声明见 `GPS_GUI_THIRD_PARTY_NOTICES.md`。

## 验证

Ubuntu 24.04 干净容器安装并运行冻结程序自测通过；本地 45 项自动化测试、Ruff 和 mypy 通过。Windows runner 执行了测试、onedir 与 onefile 冻结程序自测。自测涵盖窗口启动、ExifTool、合成 JPEG 坐标回读、原片字节和 JPEG 像素不变；实际 Windows 图形点击操作仍建议在目标电脑检查。NEF Nikon 查看器人工检查尚未完成。
