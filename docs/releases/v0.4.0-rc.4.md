# Auto Image Mark Tool v0.4.0-rc.4

修复含大量 Adobe 编辑元数据的 JPG 处理失败：ExifTool 对蒙版笔刷列表的 1000 项提取上限警告带有 `[x2]` 等重复次数时，仍能完成坐标与水印处理。

- 同时兼容未参与复制的 Camera Raw / Lightroom 编辑列表、Photoshop DocumentAncestors 和 XMP History 的列表超限与处理缓慢提示。仅按已知警告格式及当前复制范围忽略；不全局忽略所有 minor 错误。所需元数据、损坏、读写失败、其他及混合警告仍严格检查。
- 增加真实 ExifTool 合成 JPG 回归，验证重复蒙版、不同笔刷和文档历史场景，以及 GPS、拍摄时间、版权、像素、ICC 和原片保护。冻结程序的 19 类离线自检包含重复蒙版和文档来源列表场景，两平台构建及公开 Windows EXE 下载后执行。
- Windows x64 提供单文件 EXE 和目录 ZIP；Ubuntu 24.04 / Linux amd64 提供 DEB。附件包含 SHA256SUMS.txt、BUILD_INFO.json、THIRD_PARTY_NOTICES.md 和 LICENSES.zip。

沿用 JPG/JPEG 坐标、水印与 Nikon NEF 坐标副本范围，NEF 显影和水印继续暂缓。公开包不含私人照片、字体、签名或个人坐标；EXE 未签名，项目许可为 CC BY-NC-SA 4.0。验证记录见 docs/acceptance.md。
