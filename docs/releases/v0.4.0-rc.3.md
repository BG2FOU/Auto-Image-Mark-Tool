# Auto Image Mark Tool v0.4.0-rc.3

修复窗口缩小、拖动分隔条或展开作业日志时，处理流程块被压缩、编号和说明文字消失的问题。流程字号随可用空间适度调整，说明自动换行；达到可读字号下限后使用垂直滚动，所有步骤与预设按钮仍可访问，放大窗口后恢复字号。

- 保留默认坐标流程、Nikon NEF GPS 完整性校验与 JPG Adobe 蒙版警告修复。
- 增加反复缩放、展开日志和分隔条拖动的 GUI 回归；冻结程序自测增加 workflow_layout，共 18 类，在两平台构建及公开 Windows EXE 下载后验证。
- Windows x64 提供单文件 EXE 和目录 ZIP；Ubuntu 24.04 / Linux amd64 提供 DEB。附件包含 SHA256SUMS.txt、BUILD_INFO.json、THIRD_PARTY_NOTICES.md 和 LICENSES.zip。

原 v0.4.0-rc.2 Release 已按用户要求撤下，原 Git 标签保留用于追溯；本版使用新版本号，不移动历史标签。

NEF 仅写入坐标副本，显影和水印暂缓。真实样片已测 Nikon Z5、Z6 III，不宣称所有型号均完成实测。公开包不含私人照片、字体、签名或个人坐标。项目许可为 CC BY-NC-SA 4.0；EXE 未签名。支持范围见 docs/nef-gps-compatibility.md，验证证据见 docs/acceptance.md。
