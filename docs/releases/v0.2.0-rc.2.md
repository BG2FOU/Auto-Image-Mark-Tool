# GPS 图形预览版 0.2.0rc2

本版加入可预制的 WGS84 坐标列表。可在图形页面新增、编辑、删除、搜索、导入和导出坐标，并将选中坐标应用到勾选的 JPG/JPEG。列表重启后保留；Windows 便携 EXE 将 `locations.json` 保存在 EXE 同目录，Linux DEB 使用用户配置目录。页面显示实际路径。坐标文件使用版本化 JSON、原子保存及有效备份，文件损坏时可在页面点击“从备份恢复”。

## 下载

- Windows 10/11 x64：`AutoImageMarkGpsGui-v0.2.0-rc.2-windows-x64.exe`。
- Ubuntu 24.04 amd64：`auto-image-mark-gps-gui_0.2.0-rc2_amd64.deb`。
- `SHA256SUMS.txt`：下载后核对文件哈希。

## 使用与边界

先建立坐标，勾选照片后点击列表旁的“应用到勾选照片”；也可以逐行手填。选择输出目录，检查批次后写入副本，原片不变。JPG/JPEG 已放行。NEF 在独立 Nikon 查看器验收前仍受预检阻止。水印入口仍为占位。公开包不包含用户照片、商业字体或签名素材。项目许可证保留 CC BY-SA 4.0。

本版同时修复 DEB 构建脚本与 Ruff 格式检查不一致导致的 Windows CI 失败。
