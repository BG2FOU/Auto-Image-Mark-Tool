# Auto Image Mark Tool v0.5.0

修复流程侧栏首次显示时字号与滚动条的布局反馈，启动默认最大化，保留标题栏、任务栏和正常还原窗口操作。加入用户提供的 deathstar 程序图标，Windows EXE、运行窗口及 Linux 桌面入口使用该图标。

- “处理”列头文字前显示无文字全选框，部分/全部/未勾选状态同步，覆盖搜索隐藏项；点击勾选框不会触发列排序。两个多行勾选按钮位于照片计数与搜索框之间。
- 输出目录默认 EXE 所在目录，可继续手动修改；不使用单文件程序的临时解包目录，原片与已有成品保护规则不变。
- 沿用 DCT/FFT 低、中、高频域水印（默认 DCT 中档）、拍摄时间默认排序、JPG 三流程与 NEF 坐标副本处理。NEF 显影及水印仍未开放。
- Windows x64 提供单文件 EXE、目录 ZIP，Ubuntu 24.04 / Linux amd64 提供 DEB；包含 SHA256SUMS.txt、BUILD_INFO.json、第三方声明和许可归档。两平台执行 27 类冻结自检，新增程序图标加载检查，包含启动、批量选择、默认目录、DCT/FFT 实际输出恢复及原片保护。

公开包不含私人照片、字体、签名或个人配置，字体/签名仍须本地选择。EXE 未签名；发布验证不代表用户原生 Windows 人工检查记录。完整构建和公开下载证据见 docs/acceptance.md。
