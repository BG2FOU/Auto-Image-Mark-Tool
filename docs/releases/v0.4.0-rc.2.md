# Auto Image Mark Tool v0.4.0-rc.2

修复 Adobe 编辑后 JPG 的蒙版元数据警告导致水印失败，以及 NEF 坐标副本缺失 GPS 日期、卫星数和基准字段的问题，并将启动默认流程改为“坐标写入”。支持 Windows x64 与 Ubuntu 24.04 / Linux amd64。

- NEF 写入 GPSSatellites=00、GPSMapDatum=WGS-84、GPSVersionID=2.3.0.0；GPS 日期/时间读取照片 EXIF 拍摄时间及小数秒，按照片提供的时区转为 UTC，原拍摄时间保持不变。
- 主页面默认仅勾选“写入坐标”，可手动切换水印或组合流程。
- 水印元数据白名单复制时，允许未选入输出的 Camera Raw GestureDabs 列表触发已知的 1000 条提取上限警告；不全局忽略轻微错误，其他警告和执行错误仍阻止输出，GPS、拍摄时间、版权、像素及 ICC 回读检查保留。
- 面向所有 Nikon 相机 NEF，取消固定 Z5 机型、位深、尺寸和压缩模式白名单；每张照片按容器和数据完整性检查。其他品牌 RAW 暂不开放。
- 核对 NEF 主图及所有可提取预览 SHA256、拍摄/MakerNotes/XMP/IPTC/ICC 信息及 GPS 读回；无法验证或出现新增异常时不提交成品。
- 保持原片不变，输出同名 NEF 副本；NEF 显影和水印继续暂缓。JPG/JPEG 三流程及既有坐标/海拔/转换工具保留。

Windows 下载 EXE，或解压 ZIP 后运行其中的 AutoImageMarkTool.exe；Linux 安装 DEB 后运行 auto-image-mark-tool。公开附件包含 SHA256SUMS.txt、BUILD_INFO.json、THIRD_PARTY_NOTICES.md 和 LICENSES.zip；许可为 CC BY-NC-SA 4.0，EXE 未签名。

真实样片验证覆盖 Nikon Z5 和 Z6 III；合成 Nikon TIFF/NEF 容器覆盖 GPS 写入及冻结程序自测。不宣称所有 Nikon 型号/编码均已实测。缺失 EXIF 拍摄时间时不补造 GPS 日期，无时区时保留相机时钟值。Windows 资源管理器 System.GPS.Date 的显示尚未逐相机人工核验。

公开包不包含私人照片、坐标、字体或签名。完整支持边界见 docs/nef-gps-compatibility.md，验收证据见 docs/acceptance.md。旧版本和标签保持不变。
