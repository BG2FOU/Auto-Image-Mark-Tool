# Auto Image Mark Tool v0.4.0-rc.1

在已验收的 JPG 工具上增加 NEF 坐标写入，支持 Windows x64 与 Ubuntu 24.04 / Linux amd64。

- 主页面“坐标”流程可混合处理 JPG/JPEG 与已验证的 Nikon Z 5 NEF。
- NEF 输出保持同名 NEF 副本；只写 GPS，不显影、不转换或导出 JPG。
- NEF 范围限定 Nikon Z 5、14-bit lossless、RAW 6040×4032；其他机型、位深、压缩编码或异常数据布局会在检查中拒绝。
- 写入后比较压缩 RAW 数据、缩略图、嵌入 JPEG 和拍摄信息/MakerNotes；不一致则不提交成品。原片保持不变。
- NEF 不生成 JPG 预览；启用水印且勾选 NEF 会阻止整批，可取消勾选 NEF 后处理 JPG。
- 保留已实现的 JPG 三流程、自适应水印、坐标列表、表格导入、取消、报告和本地资源配置。

## 下载和校验

Windows 使用单文件 EXE，或解压 ZIP 后运行其中的 `AutoImageMarkTool.exe`。Linux 使用 `sudo apt install ./auto-image-mark-tool_0.4.0-rc.1_amd64.deb`，再启动 `auto-image-mark-tool`；包内版本为 `0.4.0~rc1`。

公开包不含原照片、字体、签名或真实坐标。程序和固定 ExifTool 随包提供；GPS-only 无需字体/签名，水印素材由用户本地选择。许可仍为 CC BY-SA 4.0，第三方许可按附件声明。

附件 SHA256SUMS.txt、BUILD_INFO.json、THIRD_PARTY_NOTICES.md 与 LICENSES.zip 分别提供校验、来源和许可信息。旧发布和标签保持不变。

## 验证范围和限制

本地授权 Nikon Z 5 样片的 RAW mosaic、尺寸、解码预览、MakerNotes、原片哈希、GPS 读回和 JPG/NEF 混合 GUI 批次已验证；破坏 RAW 数据会阻止提交。用户已确认 NEF 试写副本经独立软件检查通过，具体软件版本未提供。

发布流程检查 Windows onedir/onefile、中文含空格路径，以及 Linux DEB 解包后的 13 类冻结自测。新增 NEF 冻结检查验证拒绝和处理边界，真实 NEF 样片不上传 CI；不把合成拒绝测试称为 Windows 真实 NEF 样片写入验收。

NEF 显影与水印继续暂缓。旧 `--gps-only` 预览保留原门禁，NEF 请使用主页面“坐标”流程。EXE 未签名；特殊 Windows 用户路径仍可能需要可写的 ASCII TEMP。详细记录见 docs/acceptance.md。
