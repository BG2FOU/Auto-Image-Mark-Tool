# Auto Image Mark Tool v0.4.0-rc.5

水印步骤新增频域签名水印，支持 DCT/FFT 和低、中、高三个档位，默认 DCT 中档。批处理列表支持全选/全不选、选中多行后统一勾选/取消勾选，并默认按照片拍摄时间从早到晚排序。

- 频域水印设置附加在水印栏，可关闭；个人默认与流程预设保存算法、档位和本地随机密钥。原有可见水印继续保留，JPEG 编码及元数据传递后完整提取核验，失败不提交成片。取证提取需要原签名、算法及本地密钥；不承诺裁切、旋转后的恢复。
- 全选框显示全部、部分、未勾选状态，作用于已导入全部照片（含搜索隐藏项）。Ctrl/Shift 多行选中后，两个按钮按照片 ID 操作，排序、搜索不会串行。拍摄时间比较包括秒和小数秒；缺失或无效时间排末尾，可点击列头切换排序。
- 优化 ExifTool 会话复用、元数据读取、局部水印合成和资源缓存，维持串行处理及完整读回、源哈希、临时文件保护；NEF 坐标支持范围不变。
- 两平台构建运行 23 类离线冻结自检，包含 DCT/FFT 正式输出及恢复、批量勾选和时间排序。Windows x64 提供单文件 EXE、目录 ZIP；Ubuntu 24.04 / Linux amd64 提供 DEB。附件包含 SHA256SUMS.txt、BUILD_INFO.json、THIRD_PARTY_NOTICES.md 和 LICENSES.zip。

公开包不含私人照片、字体、签名或个人密钥，首次使用需选择自己的字体与签名。NEF 显影及水印仍未开放；EXE 未签名，项目许可为 CC BY-NC-SA 4.0。自动化构建与下载验证不代表用户已完成原生 Windows 人工验收。验证记录见 docs/acceptance.md。
