# JPG 图形页面使用手册

## 1. 选择流程与照片

从 [v0.3.0-rc.1 Release](https://github.com/BG2FOU/Auto-Image-Mark-Tool/releases/tag/v0.3.0-rc.1) 下载 Windows EXE/ZIP 或 Linux DEB，启动 `AutoImageMarkTool.exe` / `auto-image-mark-tool`；源码运行使用 `python -m aim_tool`。左侧选择“坐标”“水印”或“坐标＋水印”。步骤顺序固定为坐标在前、水印在后；至少启用一个处理步骤。可保存/载入本地流程预设，当前不导入 NEF。

点击添加照片/文件夹，或将 JPG/JPEG 拖入窗口。复选框控制处理范围；当前选中行控制右侧预览。可以搜索和排序；批量应用按照片稳定 ID 工作，排序不会改变对应关系。可移除选中行，不会删除原文件。

## 2. 坐标列表

选择坐标流程后，页面下方显示 WGS84 坐标列表。可新增、编辑、删除、搜索、导入/导出 JSON，再应用到勾选照片；也可手填十进制纬度、经度。坐标范围分别为 ±90 / ±180，必须成对填写，程序不转换 GCJ-02。

Windows 便携版 `locations.json` 在 EXE 同目录；目录必须可写。其他配置位于本机用户配置目录。备份恢复不会静默覆盖损坏的配置。已有海拔等附属 GPS 时，须明确选择允许清除，更新只发生在输出副本上。

## 3. 内容、日期与表格

航空/铁路编号使用大写字母、数字、连字符；风光支持所选字体覆盖的内容。顶部批量输入只应用到勾选照片，空的内容/日期不覆盖已有值。也可双击行的类别、内容、日期、经纬度单元格编辑。

日期优先级：手动 > 表格 > EXIF DateTimeOriginal > 明确允许的 CreateDate。支持 `2026-09-26`、`2026/09/26`、`2026/9/26` 与计划中的完整时间格式，水印显示 `2026/09/26`。保留原日历日，不切换到 UTC；不使用今天或文件修改时间。清空手动日期恢复自动来源；原 EXIF 拍摄时间不会因水印日期修改而改变。日期来源在表格和预览中显示。

导入 CSV/TSV/XLSX，或粘贴包含表头的 Excel TSV。标准字段为 `file_name,category,subject,capture_date,location_name,latitude,longitude`；中文标准表头自动识别。自定义列映射每行填写 `原表头=标准字段`，类别值为 `aviation/railway/landscape`。编码默认 UTF-8，GB18030 必须手选；XLSX 可填写工作表名，留空用首个工作表。

后台完成唯一文件匹配后显示预览。重复、歧义、未匹配、公式和不合法日期会阻止应用；输入改变会使旧预览失效。确认后才应用，不按行号猜测照片，也不把空单元格当成清空操作。

## 4. 水印设置与预览

“水印设置”可选择本地 TTF/OTF/TTC、字体 face 和透明 PNG 签名；检查后显示内部字体名称和深色签名预览。航空/铁路只需拉丁字体与签名，中文风光还需中文字体。不静默替换缺字字体。

项目默认基准为 6016×4016、300 ppi：36 pt 对应 150 px；签名宽 300 px、右下边距 25 px、各段不透明度 50%。例如 5038×3363 图像按约 0.837 比例缩放，字号 126 px、签名 251 px、可见边距 21 px。照片本身不缩放，DPI 标签不改变水印比例。竖幅按交换后的基准方向适配，方幅/全景取可容纳的较小比例。

可调整大小、四角锚点、偏移、颜色、各段不透明度、JPEG 质量和色度采样。签名保持比例和原 Alpha，只施加一次不透明度。文字过长或位置越界时先报错，不截断或悄悄缩小。

“应用”只修改本次会话；“保存为我的默认”写本地设置，重启后恢复；“恢复项目默认”回到项目给定资源和参数。公开安装包不含字体或签名，需要本机选择。

右侧可适应画面或查看 100% 水印局部；可切换背景。在适应画面中拖动可见水印调整位置，导出会按原像素重新渲染。切图或改参数后丢弃过期预览，只显示最新请求。

## 5. 预检、运行与结果

选择与原片目录不同的输出目录，先检查批次，再开始处理。预检在后台核对整批输出冲突、坐标、日期、素材、缺字及布局；任一预检错误都不创建输出。点击开始会重新预检，作业固定配置与素材指纹。

坐标流程保留原文件名及格式，不重编码图像；水印流程输出 `_marked.jpg`，统一 sRGB，方向归一化一次，保留实际像素、DPI、拍摄信息、版权和当前 GPS。组合流程的 GPS 来自已定位副本。已有输出、源目录别名及已标记输入按保护规则拒绝，不覆盖原片或成品。

运行时禁用编辑，取消会在当前不可中断操作结束或超时后停止后续处理；关闭窗口也先取消并等待线程安全退出。失败不提交半成品，已成功项保留。完成后可勾选失败/取消项重试，避免重新处理成功项；状态和详细错误在表格/作业日志中查看。

结果报告只在点击导出后保存，包含输入路径、状态、输出、步骤、错误和警告，不包含专门的坐标字段；不自动上传。照片自身可能含 GPS，请按分享对象决定是否公开成品。

## 尺寸和色彩限制

预览及水印处理接受不超过 6000 万像素的 JPG/JPEG，签名原图不超过 1600 万像素；超限时明确报错，不自动降低原片分辨率。文字或签名超出画布也会阻止导出，可调整字号、宽度和位置。坐标-only 不解码或重编码照片。

有合法 ICC 的输入转换为 sRGB；损坏或与像素模式不匹配的 ICC 会报错。无 ICC 的 RGB/灰度图会提示采用 sRGB 假设；无 ICC 的 CMYK 不处理，以免错误解释色彩。

## 当前验证边界

完整 JPG 版 `v0.3.0-rc.1` 已发布；Windows 原生 CI、两种冻结包、中文含空格安装路径和公开 EXE 下载后自测均已通过。Linux DEB 构建与解包自测通过；各平台公开下载验收结果记录于 [验收记录](acceptance.md)。这些自动化检查不替代独立 Windows 10 桌面人工操作，EXE 尚未签名；NEF 功能延后。

中文安装目录缺少 DOS 短路径时，固定包内 ExifTool 运行时会临时复制到用户目录，结束后清理。若系统 TEMP 和 LOCALAPPDATA 同时不能由系统代码页或短路径表示，程序会明确报错，此时需设置可写的 ASCII TEMP。照片、字体、签名和作业配置不会因此被复制进公开包。
